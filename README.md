# Portfolio Website

## Tech Stack
- React (Vite)
- Spring Boot
- MySQL / Postgres
- JWT Authentication

## Features
- Project showcase
- Contact API
- JWT authentication (admin)
- REST APIs

## Live Demo
https://portfolio-website-rt4o.onrender.com/

## Backend APIs
- /api/v1/projects
- /api/v1/contact
- /api/v1/health

## Setup Instructions

### Backend
cd backend
mvn spring-boot:run

### Frontend
cd frontend
npm install
npm run dev
